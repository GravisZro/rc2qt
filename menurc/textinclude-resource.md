# TEXTINCLUDE resource

Defines a special resource used by the Visual C++ Resource Editor to store metadata about how the resource script should be constructed and modified. TEXTINCLUDE blocks allow the editor to add, remove, and reorder resources while preserving code comments, preprocessor conditions, and hand-edited sections.

``` syntax
textincludeID TEXTINCLUDE [DISCARDABLE]
BEGIN
    "string" . . .
END
```

## Parameters

<dl> <dt>

<span id="textincludeID"></span>*textincludeID*
</dt> <dd>

An integer identifying the TEXTINCLUDE slot. The Resource Editor uses three standardized slots:

| Slot | Purpose |
|------|---------|
| 1    | Header file containing symbol definitions |
| 2    | Read-only system/framework symbol definitions |
| 3    | Compile-time directives and appended resources |

</dd> <dt>

<span id="string"></span>*string*
</dt> <dd>

One or more null-terminated string literals. The content of each string is interpreted according to the slot number. Embedded quotes are escaped by doubling them (`""`). Carriage return/line feed sequences (`\r\n`) are preserved in the output.

</dd> </dl>

## Remarks

The Resource Editor reads these blocks to understand the structure of the `.rc` file. When the editor writes changes back to disk, it uses the slot contents to determine which files to `#include`, which header contains user-defined IDs, and what preamble to emit. The editor never modifies the content of slot 3 directly; it appends new resources before the slot 3 payload in the compiled output.

Certain attributes are also supported for backward compatibility. For more information, see [Common Resource Attributes](common-resource-attributes.md).

## Slot Descriptions

### Slot 1 — Symbol Header File

``` syntax
1 TEXTINCLUDE DISCARDABLE
BEGIN
    "resource.h\0"
END
```

Tells the Resource Editor which `#include` header file contains the numerical symbol definitions (`#define ID_BUTTON1 101`, etc.) for controls, dialogs, and strings. When a new control is added in the visual editor, Visual Studio writes its auto-generated identifier macro into this file.

### Slot 2 — Read-Only System Definitions

``` syntax
2 TEXTINCLUDE DISCARDABLE
BEGIN
    "#include ""afxres.h""\r\n"
    "\0"
END
```

Directs the Resource Editor to include mandatory system definitions needed during design time. The included header (typically `afxres.h` for MFC applications) provides default framework constants such as `ID_FILE_NEW`, `IDOK`, and `IDC_STATIC`. The editor marks these symbols as read-only so it will not overwrite them.

### Slot 3 — Compile-Time Directives and Appended Resources

``` syntax
3 TEXTINCLUDE DISCARDABLE
BEGIN
    "#define _AFX_NO_SPLITTER_RESOURCES\r\n"
    "#define _AFX_NO_OLE_RESOURCES\r\n"
    "#define _AFX_NO_TRACKER_RESOURCES\r\n"
    "#define _AFX_NO_PROPERTY_RESOURCES\r\n"
    "\r\n"
    "#if !defined(AFX_RESOURCE_DLL) || defined(AFX_TARG_ENU)\r\n"
    "#ifdef _WIN32\r\n"
    "LANGUAGE 9, 1\r\n"
    "#pragma code_page(1252)\r\n"
    "#endif\r\n"
    "#include ""res\\app.rc2""  // hand-edited resources\r\n"
    "#include ""afxres.rc""     // Standard components\r\n"
    "#endif\0"
END
```

This slot acts as an append-only payload. Everything inside this string block is emitted directly into the final compiled resource script at build time, bypassing the visual editor. The editor inserts all GUI-defined resources before this block.

| Section | Purpose |
|---------|---------|
| Optimization defines (`_AFX_NO_*`) | Excludes unused MFC features (splitter windows, OLE, trackers, property sheets) to reduce binary size |
| Language / code page | Sets the default language and character encoding for subsequent resources |
| External `#include` directives | Pulls in hand-written resource files (`.rc2`) and standard MFC resource bundles |

## Examples

The following example shows all three TEXTINCLUDE slots as generated by the MFC AppWizard:

``` syntax
#ifdef APSTUDIO_INVOKED
/////////////////////////////////////////////////////////////////////////////
//
// TEXTINCLUDE
//

1 TEXTINCLUDE DISCARDABLE
BEGIN
    "resource.h\0"
END

2 TEXTINCLUDE DISCARDABLE
BEGIN
    "#include ""afxres.h""\r\n"
    "\0"
END

3 TEXTINCLUDE DISCARDABLE
BEGIN
    "#define _AFX_NO_SPLITTER_RESOURCES\r\n"
    "#define _AFX_NO_OLE_RESOURCES\r\n"
    "#define _AFX_NO_TRACKER_RESOURCES\r\n"
    "#define _AFX_NO_PROPERTY_RESOURCES\r\n"
    "\r\n"
    "#if !defined(AFX_RESOURCE_DLL) || defined(AFX_TARG_ENU)\r\n"
    "#ifdef _WIN32\r\n"
    "LANGUAGE 9, 1\r\n"
    "#pragma code_page(1252)\r\n"
    "#endif\r\n"
    "#include ""res\\editor.rc2""  // non-Microsoft Visual C++ edited resources\r\n"
    "#include ""afxres.rc""         // Standard components\r\n"
    "#include ""afxprint.rc""      // printing/print preview resources\r\n"
    "#include ""afxolesv.rc""      // OLE server resources\r\n"
    "#endif\0"
END

#endif    // APSTUDIO_INVOKED
```
